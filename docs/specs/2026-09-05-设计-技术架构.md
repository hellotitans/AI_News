## 2. 技术选型与理由

| 决策 | 选择 | 理由 |
|---|---|---|
| 页面形态 | **单文件静态 HTML**(内联 CSS/JS) | 无构建、无依赖、改内容即发布;QW Pages 静态托管秒级生效 |
| 字体 | Google Fonts CDN(Noto Serif SC / Noto Sans SC / Playfair Display) | 不引入本地字体文件,保持单文件 |
| 托管 | QW Pages | 固定域名、覆盖发布、无需运维 |
| 自动化 | QwenWork Cron(cron 表达式 `0 8 * * *`,tz Asia/Shanghai) | 与会话同环境,能直接调用搜索/发布工具 |
| 断档策略 | `missedRunPolicy: run_latest` | 电脑未开机时,开机后补跑最新一期,不重复堆叠 |
| 动效 | 原生 CSS transition + 少量 JS(classList + dataset) | 不引 GSAP 等库,零依赖,60fps 无压力 |
| 头图 | 生图模型 2K → PowerShell 缩放压缩为 JPG | 6.3MB PNG → 330KB JPG,保证加载速度 |

## 3. 关键文件与依赖

```
daily-ai-frontier/
├── index.html      ← 唯一需要每日修改的文件
│     ├── <head> 内:标题日期(3 处: title / .date / footer)
│     ├── 报头:Vol 期数、日期、星期
│     ├── 头条区:kicker / H2 / 导语 / 正文 / 数据卡×3 / 编辑点评 / 侧栏档案
│     └── 榜单:02~07 六个 <article class="rank-item">
├── hero-web.jpg    ← 头条插画(相对路径引用,随目录一起发布)
└── hero.png        ← 原始图(不发布引用,仅存档)
```

**硬依赖(不可破坏)**:
- `daily-ai-frontier/` 目录绝对路径 —— cron 任务 payload 与发布配置均写死此路径,**不可移动/重命名**
- `hero-web.jpg` 文件名 —— index.html 相对引用

## 4. 每期更新的固定修改点(Checklist)

| # | 位置 | 修改内容 |
|---|---|---|
| 1 | `<title>` | 日期 |
| 2 | `.topline > span` | Vol.XXX 期数顺延 |
| 3 | `.issue-info .date` + 星期 | 当日日期、星期 |
| 4 | 头条 kicker | 分类词 |
| 5 | 头条 H2 / 导语 / 正文 2 段 / 数据卡×3 / 编辑点评 | 全部替换 |
| 6 | 侧栏:热度指数 / Fact Sheet / 来源 | 全部替换 |
| 7 | 榜单 02~07 六个 article | 全部替换 |
| 8 | 页脚 | 日期 + 期数 |
| 9 | (可选)hero-web.jpg | 头条主题严重不符时才重绘 |

## 5. 发布流程

```
1. 保存 index.html
2. qwenwork_pages_publish:
   { category: "static",
     file_path: "D:\\QwenWork_Project\\AI_News\\daily-ai-frontier",
     name: "前沿日报 · The Frontier Daily" }
3. 验证:WebFetch 线上页面,逐项核对(日期/期数/头条/榜单/无残留/无乱码)
4. 快照归档:cp index.html archive/issues/Vol.XXX-日期.html
5. 会话推送简报
```

## 6. 故障处理

| 症状 | 原因 | 处置 |
|---|---|---|
| 早 8 点后页面日期未变 | 电脑未开机 / cron 未触发 / 任务执行失败 | 用户说「刷新一下日报」→ 手动补更;检查 cron 任务状态 |
| 页面出现旧期内容残留 | 更新时替换不完整 | WebFetch 验证清单必查「残留」项;发现即修正重发 |
| 图片裂图 | hero-web.jpg 未随目录上传 | 确认 filesUploaded=3;curl 检查图片 200 |
| WebFetch 验证超时 | 网络抖动 | 重试一次;或 curl 检查首页 200 |

## 7. 已知限制

1. 单文件 HTML 意味着**每期旧内容会被覆盖**——历史期次仅存在于 archive/ 快照(且 Vol.001~008 未留快照,自 Vol.009 起归档)
2. cron 依赖本机 QwenWork 运行;长期停机期间日报停更(开机补跑)
3. 无访客统计(单人使用,暂不需要)
