# 设计文档:视觉风格与版面

**日期**:2026-09-05(设计定稿)· 2026-09-13(整理归档)
**风格定位**:编辑杂志风(Editorial Magazine)—— MONOCLE / WIRED 的纸质质感,而非科技媒体常见的暗黑风

---

## 1. 设计理念

AI 新闻天然带着「未来感」,市面上的 AI 资讯页几乎清一色深色 + 霓虹。本项目反其道而行:**用最传统的印刷美学承载最前沿的内容**,形成反差记忆点。设计的核心隐喻是「每天出版的报纸」——报头、期数、双细线分隔、首字下沉,都是印刷时代的仪式感。

## 2. 设计系统(Design Tokens)

### 2.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#f7f3ea` | 页面底色,暖米白纸感 |
| `--paper-deep` | `#efe9db` | 编辑点评块底色 |
| `--ink` | `#1a1815` | 正文墨色(非纯黑) |
| `--ink-soft` | `#4a453d` | 次级文字 |
| `--ink-faint` | `#8a8375` | 辅助信息 |
| `--vermilion` | `#c0392b` | 朱红:主强调色(热度、头条英文、装饰线) |
| `--blue` | `#1f3a5f` | 藏青:链接与「模型」标签 |
| `--gold` | `#a67c2e` | 「收购/资本」标签 |
| `--teal` | `#16665a` | 「泛科技」标签 |
| `--rule` | `#d8d0bf` | 分隔细线 |

配色纪律:**墨色系负责信息,朱红只做点睛**——全页朱红面积不超过 5%,保证「贵」而不闹。

### 2.2 字体

| 字体 | 用途 | 说明 |
|---|---|---|
| Noto Serif SC 900 | 报头、头条、榜单标题 | 衬线特粗,印刷标题感 |
| Playfair Display | 英文刊名、日期、大数字、期号 | 意大利体做点缀,热度数字用衬线体显「计分牌」感 |
| Noto Sans SC | 正文、辅助信息 | 保证长文阅读效率 |

英文衬线 + 中文宋体的组合是「双语杂志」的经典做法。

### 2.3 质感与纹理

- **纸张噪点**:全页覆盖 SVG fractalNoise,`opacity: 0.035`,只可感知不可注目
- **双细线**(double rule):报头下方 3px + 1px 双横线,报纸版式的身份符号
- **头条插画**:risograph 印刷风(奶油底 + 藏青 + 珊瑚红三点色),与页面色彩系统同源

## 3. 版面结构(自上而下)

### 3.1 报头 Masthead

```
AI · 科技 · 前沿观察          Curated by QwenWork          Vol.009
前沿日报 The Frontier Daily(衬线大字 + 英文斜体)
2026 / 09 / 13  星期日 · 更新版  每日 08:00 自动更新
══════════════════(双细线)══════════════════
```

### 3.2 头条特写区(左右 1fr + 340px 两栏)

左主栏:
- **Kicker**:朱红小字「头条 · THE LEAD · 分类」+ 前置短横线
- **H2 大标题**:48~56px 衬线,专有名词用 Playfair 斜体朱红
- **导语**(hero-sub):衬线中号字,一句话定调
- **插画**:figure + 图注(插画名 / THE FRONTIER DAILY)
- **正文 2 段**:首字下沉(74px Playfair 朱红首字母)
- **数据卡 ×3**:三栏,大数字 + 小标签,用于量化新闻要点
- **编辑点评**:米深底 + 朱红左边线 + 「编辑点评 · Why It Matters」标签

右侧栏(细线分隔):
- 热度指数大数字(88px Playfair)+ 动态热度条
- 档案 Fact Sheet(发布方、时间、类型等键值对)
- 来源 Source + 原文链接

### 3.3 热度榜(02~07)

每条三栏 grid:`130px 编号 | 1fr 正文 | 230px 侧栏`

- **编号**:78px Playfair 描边空心数字,hover 时填充实红——「排名」的仪式感
- **标签行**:圆角描边小标签,按分类着色(模型=藏青、资本=金、产品=朱红、泛科技=青)
- **正文**:标题(24px 衬线)+ 左右对齐摘要
- **侧栏**:热度值 + 热度条 + 编辑点评(细线上分隔)+ 来源链接

条目间用 1px 细线分隔,hover 时背景微白——安静但有反馈。

### 3.4 页脚

深墨色底反白,与浅色正文形成「封底」感;标注选题范围、热度指数口径、期数。

## 4. 动效规范

| 动效 | 参数 | 目的 |
|---|---|---|
| 入场渐显上移 | `opacity 0→1, translateY 28px→0`,0.9s,cubic-bezier(.16,1,.3,1),按 d1~d7 级联 0.05~0.88s | 页面像「展开的报纸」 |
| 热度条生长 | `width 0→N%`,1.6s,delay 0.5s | 数据的「计分感」 |
| 榜单 hover | 编号描边→实红填充 0.35s | 微反馈 |
| 尊重偏好 | `prefers-reduced-motion: reduce` 全部关闭 | 无障碍 |

## 5. 响应式

| 断点 | 变化 |
|---|---|
| ≤1020px | 头条变单栏(侧栏移到正文下方);榜单变两栏,侧栏并入 |
| ≤720px | 主栏 padding 收窄;报头纵排;标题降字号;数据卡纵排;榜单单栏 |

## 6. 头条插画规范

- 风格:risograph/编辑插画,奶油纸底,与页面同源的三点色
- 比例:16:9,2K 分辨率,导出为 JPG(质量 88,目标 <350KB)
- 内容:抽象概念图(神经网络、星光、网络节点),**不含文字**
- 复用原则:主题不严重冲突时沿用,不必每日重绘

## 7. 禁忌清单(编辑纪律)

- 不用暗黑底、霓虹渐变、玻璃拟态——与杂志风冲突
- 不用 emoji 做装饰(数据卡内容除外)
- 朱红不用于大段文字,只做强调
- 每期只换内容区,不改版式——用户的熟悉感就是设计的一部分
