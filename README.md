# 前沿日报 · The Frontier Daily

> 每日早 10 点自动更新的 AI 与科技前沿新闻日报 —— 编辑杂志风网页,头条特写 + 热度榜单,由 AI 自动检索、撰写、发布并推送。

**线上地址**:https://6y4zppa9.qwenwork.host/(固定不变,每日更新内容)
**当前版本**:V0.0(创刊九期 + 项目管理体系,2026-09-13)

---

## 这是什么

一个完全由 AI agent 无人值守运营的「个人日报」:

- **每日 10:00**(北京时间)定时任务自动执行:多源检索过去 24~48 小时 AI/科技热点 → 筛选 5~7 条(AI:泛科技 ≈ 7:3)→ 按热度排序编排 → 改写页面内容 → 发布上线 → 归档快照 → 推送当日简报
- **版面设计**:编辑杂志风(纸质底色、衬线大标题、朱红点缀、首字下沉、描边期号),头条特写区 + 02~07 热度榜单,重要性与热度直接映射为视觉层级
- **内容风格**:每条必带「编辑点评 · Why It Matters」,拒绝旧闻翻炒,热度指数 0~100 标注口径
- **往期回顾**:线上历期头条索引页(archive.html),本地保留每期完整快照

## 运行依赖

本项目依托 QwenWork 桌面端运行(定时任务、搜索、发布均为其内置能力),站点托管于 QW Pages。如需在本仓库基础上二次开发页面,`daily-ai-frontier/` 是纯静态单文件 HTML,无构建依赖,直接用浏览器打开即可预览。
