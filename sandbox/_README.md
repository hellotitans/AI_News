# sandbox/ — 开发沙箱

## 这是什么

`daily-ai-frontier/` 的**开发副本**，用于在不触碰生产环境的前提下折腾页面。

## 为什么必须有它

生产目录 `daily-ai-frontier/` 被 cron 定时任务（`0fc4f854-938a-4a8c-b715-c710afc4b9c4`，每日 08:00）**按整个目录发布**到 QW Pages。这意味着：

- 在生产目录里新建任何文件 → 下次发布时被一并上传、可被直接访问
- 在生产目录里改坏任何文件 → 线上立刻生效，没有回滚按钮
- 验证标准 `filesUploaded` 数量会因新增文件而变化，容易掩盖真正的发布异常

所以：**所有新页面先在这里出生，确认后再同步。**

## 使用约定

1. **在这里随便改**。删除、重排、试错都不影响线上。
2. **同步用「覆盖复制」，不用移动**。确认定稿后，把确定的文件复制到 `daily-ai-frontier/`，沙箱保留继续迭代。
3. **同步前对照 Checklist**：
   - [ ] 相对路径在根目录层级下依然成立（`index.html`、`hero-web.jpg` 均为同级引用）
   - [ ] 字体走 Google Fonts CDN，没有引入本地字体文件
   - [ ] 没有引入任何构建依赖，仍是单页 HTML
   - [ ] 发布后用 WebFetch 核对 `filesUploaded` 数量的变化是否符合预期
4. **不要把这个目录整体作为发布目标**。发布配置里的路径必须始终是 `daily-ai-frontier/`。

## 当前在做的东西

《观察席 · The Observatory》—— 日报的关联页面，单页双板块：

- **板块一** 大众情绪与行业演化观察（第一主角）
- **板块二** 当日热点科技拆解：图文 + 内联 SVG 架构图 + 亮点/难点拆解 + 日常比喻 + 预设追问
- 两个板块末尾各有一块**笔记区**（纸上的填空线样式），供费曼式复述

已定型的七个决策：本地 localStorage 存储 + 导出 Markdown；静态书写不做 AI 对话、改为预设追问；内容由会话点题手动更新而非进 cron；每日一期 + 往期索引；单页双板块 + 页内锚点导航；科普选题优先锚定当日新闻；第一期不做语音输入（预留位置）。

**注意**：目前 `observatory.html` 是静态视觉稿 —— 只有结构、样式和示例内容，**笔记区的存储与导出逻辑尚未实现**。

## 页面导航拓扑

四个页面之间必须能互相走通，相对路径均为**同级引用**（不依赖服务器根目录 Rewrite，`file://` 双击打开也能跳转）：

```
                    ┌──────────────────────┐
                    │      index.html      │  日报首页
                    └──────┬───────┬───────┘
                报头下入口条  │       │  报头下入口条
                           ▼       ▼
        ┌──────────────────────┐  ┌──────────────────────┐
        │   observatory.html   │  │     archive.html     │
        │   观察席（开发中）    │  │      往期回顾         │
        └──────┬───────────────┘  └──────┬────────────────┘
               │                         │
    报头 back-link               报头 back-link + 页脚文字链
               └──────────┬──────────────┘
                          ▼
                    返回 index.html
```

**约定**：每个副刊页面统一在**报头 `masthead` 右侧**放返回链接（`← 返回今日日报`），使用 `.back-link` 样式，与 `archive.html` 保持一致。新增页面请沿用。

⚠️ **不要用 `href="./"`**。这种写法只在 HTTP 服务器下解析到 index.html，用 `file://` 双击打开时会指向目录本身导致跳转失败。一律写明确的 `index.html`。（`archive.html` 原有的两处 `./` 已修正。）
